  • Component / Instance scoped globally accessible contexts
  • Still... no wrapper, but yet you gain access to a unique context system that you can use how ever, whenever, or where ever you need to. There are 3 levels of abstraction
  1. 'component' or 'instance' defined scope
  2. 'group' or 'category' defined scope
  3. 'app' or 'umbrella' defined scope

The best part is the usage was created, BACKWARDS so as to allow for a much more easier, more userfriendly ux. Only want to scope it by comp or instance... great you just supply one value. Need to take it a step further? Great, supply 2. If you need or desire to decouple your newly created context from the global context entirely, you simply just supply 3 values. Thats it...

- const defaultValue = 'dark'
- const userDefinedLabel = 'theme'
- const component_defined_scope = 'hover_card'
- const themeContext = createSauronContext(defaultValue, userDefinedLabel, component_defined_scope)
- const theme = useSauronContext(ThemeContext)

- const group_defined_scope = 'ui_components'
- const umbrella_defined_scope = 'my_cool_ui_comps_library'

- const themeContext = createSauronContext(defaultValue, userDefinedLabel, component_defined_scope, group_defined_scope, umbrella_defined_scope)

Gates: Declarative Flow & Immutable Reactive Chaining

A zero-friction, hybrid sync/async conditional routing and state-chaining engine designed for modern TypeScript applications. It combines pattern-matching logic gates (switch, if, ifelse) with an immutable reactive flow wrapper (ReChain via Maybe_ReChain).

🚀 First-Time Users (Get Started in Under 5 Minutes)

If you just want to evaluate a value conditionally without dealing with boilerplate or forced await keywords, use the Gates utility right out of the box.

1. Basic Switch Routing

Match a string value against a set of handlers. Because of the built-in MaybePromise wrapper, you can treat it as a synchronous value or await it if your handlers are asynchronous.

import { Gates } from "./path-to-component";

// Instantly evaluate a value using switch-case logic
const result = Gates('red', 'switch', {
  red: (val) => ({ hex: '#FF0000', name: val }),
  blue: (val) => ({ hex: '#0000FF', name: val }),
  default: (val) => ({ hex: '#000000', name: 'unknown' })
});

console.log(result); 
// Output: { red: { hex: '#FF0000', name: 'red' } }

2. Sequential ifelse Routing

To execute branches sequentially and halt processing on the first match (like an if / else if ladder):

const authResult = Gates('user', 'ifelse', {
  admin: (val) => '/admin-dashboard',
  user: (val) => '/user-profile',
  default: (val) => '/login'
});

🛠️ Advanced Usage & Architecture

For teams building complex reactive data layers, this component bridges Condition Routing with Immutable Reactive Chaining (ReChain).

How It Works Under the Hood

  1. ConditionEngine: Evaluates inputs against maps or objects of condition branches. It supports three execution modes:
  • 'switch': Evaluates keys, runs the first match (plus an optional default fallback), and exits.
  • 'if': Evaluates all entries and executes matching branches concurrently via Promise.all.
  • 'ifelse': Executes matching branches sequentially, stopping immediately on the first success or error.
  1. **Maybe_ReChain & MaybePromise**: Unlike traditional async utility wrappers that force you to use await everywhere, MaybePromise returns raw synchronous data immediately if the value is available right away—falling back to a proper Promise only when delayed or async operations are necessary. The resulting output is automatically wrapped inside an immutable ReChain instance for fluent stream-style execution.

Comprehensive Code Examples

Advanced Match Predicates & Regular Expressions

You can target values using direct keys, helper objects with explicit matchers, or standard regular expressions:

const result = Gates('user_992', 'switch', {
  // RegExp string syntax or direct RegExp patterns
  '/^user_/': (val) => `Found standard user: ${val}`,
  
  // Complex predicate object format
  admin: {
    match: (val) => val.includes('admin'),
    run: (val) => `Elevated privileges granted for ${val}`
  },
  
  default: (val) => `Unrecognized entity: ${val}`
});

Dynamic Context Injection

Pass a factory function into Gates to gain access to contextual stubs (self, config, variables):

const dynamicResult = Gates('error_404', 'switch', ({ self, config, variables }) => ({
  error_404: (code) => variables.renderCustomError(code, 404),
  error_500: (code) => variables.renderCustomError(code, 500),
  default: (code) => variables.renderDefault()
}));

Direct ConditionEngine Usage

If you prefer raw control without the automatic ReChain boundary wrapper, you can instantiate and evaluate the engine directly:

import { ConditionEngine } from "./path-to-component";

const engine = new ConditionEngine('submit-action', 'switch', {
  submit: async (action) => {
    const res = await fetch('/api/submit', { method: 'POST' });
    return res.json();
  },
  default: () => ({ skipped: true })
});

const executionResult = await engine.evaluate();

#### STORAGE CONTEXT
each db has been created as its own standalone solution but have been made accessible through the bus to bring them all together under one data god solution. the wizards staff is like data to us developers hence the name... staff.

    - global instance
    - workspace instance
    - client side global instance
    - client side workspace instance
    - note: now the term client side used here is deceptive... it doesn't mean it is only available client side, it can also be used server side as well. It acheives this by using the bus with creating an rpc version of the servers db instance. Personally I just create the server side instance once... and never touch it again, as the 'client side' is the one I always import and use every where due to its ease of use

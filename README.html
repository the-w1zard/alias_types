TYPESCRIPT ALIAS

This pkg includes extremely agressive alias of typescripts definitions.

An ultra-concise, ergonomic collection of global TypeScript type aliases, shorthand primitives, and advanced utility helpers designed to speed up type-safe development.

💡 Example Usage

// Using short primitives and record structures
const user: R<S, A> = {
    name: "Alice",
    age: 30
};

// Using utility helpers like Deep Partial and Awaited Promises
type Config = DEEPP<{
    server: {
        host: S;
        port: N;
    };
}>;

async function fetchData(): P<AR<S>> {
    return ["item1", "item2"];
}
